🎯 Face Recognition Attendance System

This project is a web-based Face Recognition Attendance System built using Flask, Python, HTML, CSS, and JavaScript. It automates the attendance process by using real-time webcam-based face recognition. The goal of this project is to eliminate manual attendance, prevent proxy attendance, and demonstrate practical implementation of computer vision and web development concepts.

🛠️ Tools & Technologies Used

Python (Flask)

HTML5

CSS3

JavaScript (Vanilla JS)

OpenCV

face_recognition

Gmail SMTP (Email Service)

📌 Key Features

Webcam-based user registration with face capture

Automatic generation of a unique 5-digit User ID

Real-time face recognition for attendance marking

Attendance allowed only when the Mark Attendance section is active

30-minute cooldown to prevent duplicate attendance

Email notifications for successful registration and attendance

Attendance records displayed in a structured table format

🎨 UI & System Highlights

Clean and minimal web interface

Tab-based navigation for registration, attendance, and records

Live camera preview for user interaction

Simple and user-friendly workflow

📱 Responsiveness

The application is designed to work smoothly on modern desktop browsers with webcam support, providing a consistent and reliable user experience.
